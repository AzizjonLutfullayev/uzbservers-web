Biz haqimizda

UZB SERVERS — O‘zbekiston Counter-Strike 1.6 serverlarini bitta zamonaviy platformada topish, kuzatish va serverlarga ulanishni osonlashtirish uchun yaratilgan loyiha.

Platforma ochiq manbalardagi server ma’lumotlarini boshlang‘ich ro‘yxat sifatida ishlatadi va CS 1.6 serverlarini avtomatik monitoring qiladi. Server holati, o‘yinchilar soni, xarita va ping kabi ma’lumotlar monitoring natijasiga qarab yangilanadi.

Bizning maqsadimiz — O‘zbekistondagi faol CS 1.6 serverlarini topishni qulay qilish, o‘yinchilar uchun server tanlashni osonlashtirish va mahalliy Counter-Strike hamjamiyatiga foydali katalog yaratish.
